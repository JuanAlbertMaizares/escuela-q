# Escuela de Detectives Q - Persistence Lab

Laboratorio de persistencia para practicar el patrón Repository utilizando **NestJS 12**, **TypeORM** y **Neon (PostgreSQL)**.

## 🛠️ Tecnologías

- **Framework:** NestJS 12
- **ORM:** TypeORM
- **Base de Datos:** Neon (PostgreSQL Serverless)
- **Lenguaje:** TypeScript
- **Gestor de Paquetes:** pnpm

## 🚀 Requisitos Previos

- Node.js (v20.19+ o v22.12+)
- pnpm
- Una cuenta en [Neon](https://neon.tech/) con una base de datos PostgreSQL.
